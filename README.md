# Юный инвестор — HTML5-игра для трека «Игры»

**Задача обучения:** после игры ребёнок умеет объяснить, почему цена акции растёт или падает после новости,
отличает слух от факта и понимает, зачем распределять монеты между несколькими компаниями.

## Как играть
1000 учебных монет, 6 игровых дней (3–5 минут). Каждый день: утренняя новость → торги (купить / продать / подождать) → вечер:
цены меняются, Сова Финя показывает цепочку «причина → следствие». В вечер 4–6 приходят неожиданные новости.

## Наблюдаемые действия (как понять, что научились)
| Цель | Действие в игре | Награда на финале |
|---|---|---|
| Читать новости | в ≥3 днях купил акции тех, кому новость помогает, или продал тех, кому мешает | 🔍 Следопыт новостей |
| Слух ≠ факт | в день слуха не увеличил вложения в «слуховую» компанию | 🛡️ Проверяю слухи |
| Диверсификация | в день неожиданных новостей держал ≥3 компаний, и ни одна не >50% | 🧺 Мастер корзин |
| Осторожность | большая часть монет в копилке | 🪙 Спокойный хранитель |
Финальный график сравнивает «всё в одну компанию» (диапазон исходов), «поровну» и портфель игрока — по реальным ценам этого забега.

## Соответствие ограничениям
- Чистые HTML/CSS/JS, без библиотек, шрифтов и запросов наружу; относительные пути. Вес ≈ 100 КБ.
- Состояние только в памяти страницы: один вход = законченный результат; проигрыш не штрафуется (есть «Сыграть ещё раз» с другими новостями).
- Звук выключен по умолчанию, включается кнопкой 🔊.
- Нет авторизации, рейтингов, наград за деньги, таймеров и «срочности». Монеты ненастоящие, все компании вымышленные.
- Случайность — только небольшой «шум» цен и сила реакции на новость; каждое движение объясняется новостью.

## Канал в приложение (`bridge` в game.js)
`CLOSE_EVENT` — кнопка ✕; `COMPLETED_EVENT` — один раз при выходе на итоги; `FINISH_EVENT` — кнопка «Закончить»;
`VIBRATION_EVENT` — вечерняя новость и итоги; `SHARING_EVENT` — `{text, image}` (PNG data-URL).
⚠ Имена полей `text`/`image` и семантику FINISH vs COMPLETED сверить с README песочницы Android/iOS (в открытом доступе их не было).

## Управление контентом без релиза
Всё (компании, цены, новости, эффекты, пояснения, тексты Совы, расписание дней) лежит в `content.json`.
Битый или пустой файл не ломает игру: валидация и откат на `default-content.js`.
После правки JSON: `node tools/sync-default.js` обновит запасную копию. Для проверки: `?seed=123` даёт повторяемый забег.

## Уровни, день/ночь, календарь
- Перед игрой выбирается уровень (тексты — `texts.levels`). Уровень 1 — как раньше. Уровень 2: цена покупки выше цены продажи (≈ ±4%), «доверие» ★ по возрасту компании (`age`), у молодых цены прыгают сильнее, плохие новости бьют сильнее, возможны ошибки управления; новостей 1→3 в день; стартапы (`startup: true`, исход скрыт, 40% успеха, объявляется вечером).
- Закат → ночь (итоги дня читаются ночью) → кнопка «Начать новый день» → рассвет. Только CSS-переходы; при `prefers-reduced-motion` без анимации.
- Угол экрана: время года (поле `season` у новости), день недели (будний/выходной), уровень. ✕ отправляет `FINISH_EVENT`, затем `CLOSE_EVENT`.
