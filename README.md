# Юный инвестор

Детская автономная игра про акции и влияние новостей на цены. Чистые HTML, CSS и JavaScript, без библиотек и внешних запросов. Запуск — `index.html` в WebView или браузере.

## Как играть

У игрока 1000 учебных монет и 6 игровых дней. После выбора уровня и подсказок он видит краткую сводку компаний. Утром он читает новости, покупает, продаёт или ждёт. На торгах можно раскрыть подсказку Совы с объяснением влияния новости и затем свернуть её.

На втором уровне цена покупки выше цены продажи примерно на 4% от текущей цены. Компании разделены на обычные и стартапы. Стартапы могут резко расти и падать. За день появляется до трёх новостей, включая вечерние; часть из них затрагивает несколько компаний и действует несколько дней (`durationDays`). На первом уровне длительное влияние отключено.

## Итоги

Итоги дня показывают для каждой компании, была ли новость положительной, отрицательной или её не было. Финал показывает общую доходность в процентах и график стоимости портфеля по дням. Блок «Что ты теперь знаешь» остаётся на экране.

## Данные и запуск

Контент хранится в `content.json`; при ошибке загрузки используется `default-content.js`. После изменения JSON запасную копию нужно обновить теми же данными. Параметр `?seed=123` даёт повторяемый набор новостей. Состояние хранится только в памяти страницы.

## События приложения

Кнопка ✕ отправляет `FINISH_EVENT`, затем `CLOSE_EVENT`. `COMPLETED_EVENT` отправляется один раз при выходе на итоги, `VIBRATION_EVENT` — при вечерней новости и на финале. Кнопка «Закончить» на финале возвращает к выбору уровня.
